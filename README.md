# La-Pauta-Mic-Pro
La Pauta Mic Pro es un clon del C-800G, el micrófono de tubo que define el sonido moderno del hip-hop, trap y R&amp;B. Con cápsula de gran diafragma, refrigeración Peltier y brillo cristalino, captura voces con detalle, aire y presencia de radio. Recrea su carácter, claridad y pegada para que tu estudio suene caro y profesional. Voces limpias y listas
